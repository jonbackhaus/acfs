# GTBI Tools

The tools GTBI installs are defined in [`gtbi.manifest.yaml`](../../gtbi.manifest.yaml)
(the single source of truth) and described in the top-level
[README.md](../../README.md).

For hands-on, interactive walkthroughs, see the onboarding lessons in
[`gtbi/onboard/lessons/`](../../gtbi/onboard/lessons/).

To verify what's installed on a machine:

```bash
gtbi doctor --json
```
